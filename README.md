# Mobile Phone Technology Learning Web Apps
โครงการพัฒนาเว็บแอปพลิเคชันสำหรับการเรียนรู้ รายวิชาโทรศัพท์เคลื่อนที่

## รายชื่อโฟลเดอร์หน่วยการเรียนรู้ (Learning Units)

1. **`unit-01-evolution-networks/`**
   * **หน่วยที่ 1:** วิวัฒนาการและประเภทโครงข่ายโทรศัพท์เคลื่อนที่
   * หัวข้อ: ยุคการสื่อสาร (1G - 5G/6G), สถาปัตยกรรมโครงข่าย, มาตรฐานระบบเซลลูลาร์
2. **`unit-02-signals-modulation/`**
   * **หน่วยที่ 2:** ระบบสัญญาณและการมอดูเลชันในระบบโทรศัพท์เคลื่อนที่
   * หัวข้อ: แถบความถี่, การมอดูเลชันแบบแอนะล็อกและดิจิทัล (QAM, OFDM), เทคนิคการเข้าถึงช่องสัญญาณ (FDMA, TDMA, CDMA, OFDMA)
3. **`unit-03-cellsite-repeater/`**
   * **หน่วยที่ 3:** สถานีฐาน (Cell Site) และสถานีทวนสัญญาณ
   * หัวข้อ: แนวคิดเซลลูลาร์, โครงสร้างสถานีฐาน, สถานีทวนสัญญาณ (Repeater), Handover/Interference
4. **`unit-04-device-architecture/`**
   * **หน่วยที่ 4:** สถาปัตยกรรม คุณสมบัติ และระบบปฏิบัติการของเครื่องโทรศัพท์เคลื่อนที่
   * หัวข้อ: บล็อกไดอะแกรมการทำงาน, ฮาร์ดแวร์/ชิปเซ็ต/เซนเซอร์, ระบบปฏิบัติการ (Mobile OS)
5. **`unit-05-installation-testing/`**
   * **หน่วยที่ 5:** การติดตั้ง การตรวจวัด และทดสอบระบบสัญญาณ
   * หัวข้อ: เครื่องมือวัดและทดสอบ (Spectrum Analyzer), การติดตั้งอุปกรณ์, การวัดคุณภาพสัญญาณและการทดสอบ
6. **`unit-06-repair-maintenance/`**
   * **หน่วยที่ 6:** การตรวจซ่อมเครื่องโทรศัพท์เคลื่อนที่และการบำรุงรักษาระบบ
   * หัวข้อ: การตรวจซ่อมฮาร์ดแวร์และซอฟต์แวร์, แผนภาพตรวจเช็กอาการเสีย, การบำรุงรักษาเชิงป้องกันและการปฏิบัติตามมาตรฐานความปลอดภัย
