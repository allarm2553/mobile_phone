Hardware & OS Lab

บล็อกไดอะแกรมการทำงานของเครื่องโทรศัพท์เคลื่อนที่ (Functional Block Diagram)

การทำงานประสานกันของ 4 ภาคหลัก: ภาควิทยุ (RF Section), ภาคประมวลผลเบสแบนด์และแอพพลิเคชัน (Baseband/AP), ภาคจัดการพลังงาน (PMIC) และภาคส่วนติดต่อผู้ใช้ (UI/Sensors)

Interactive Hardware Topology

แผนผังระบบฮาร์ดแวร์สมาร์ตโฟน (คลิกแต่ละบล็อกเพื่อดูรายละเอียด)

คลิกที่กล่องเพื่อสลับข้อมูลอธิบายด้านล่าง

เจาะลึกชิ้นส่วนฮาร์ดแวร์บนเมนบอร์ด (SoC & Key Components)

สถาปัตยกรรมชิปเซ็ตแบบ System-on-Chip (SoC) เช่น Qualcomm Snapdragon, Apple A-Series, MediaTek Dimensity

🧠

SoC (System-on-Chip)

รวมหน่วยประมวลผลหลักไว้ในซิลิคอนชิปเดียว:
• CPU: แกนประมวลผลสถาปัตยกรรม ARM (Cortex-X / Cortex-A)
• GPU: ประมวลผลกราฟิกและเกม (Adreno / Mali)
• NPU: ประมวลผลโมเดล AI / Deep Learning บนอุปกรณ์
• ISP: ประมวลผลภาพถ่ายและวิดีโอจากกล้อง

📶

Modem & RF Front-End (RFFE)

ประกอบด้วยชิปโมเด็ม 5G (เช่น Snapdragon X65/X70) แปลงข้อมูลดิจิทัลเป็นคลื่น และแผง RFFE ซึ่งรวมชิปขยายสัญญาณ (PA), สวิตช์สลับสายอากาศ (Antenna Switch), และโมดูลจูนเนอร์ความถี่ เพื่อรองรับคลื่นทั่วโลกหลายสิบแบนด์

🔋

PMIC & Fuel Gauge (ระบบจัดการพลังงาน)

ทำหน้าที่ควบคุมการชาร์จไฟเร็ว (Fast Charging เช่น PD, QC), แปลงแรงดันแบตเตอรี่ลงเป็นแรงดันย่อยหลายสิบชุด (Core Voltage 0.8V, RAM 1.1V, I/O 1.8V) และคอยตรวจวัดสุขภาพแบตเตอรี่เพื่อตัดวงจรเมื่อเกิดความร้อนสูงหรือไฟฟ้าลัดวงจร

💾

Memory & Storage (PoP Architecture)

นิยมใช้วิธีต่อชิปแบบ Package-on-Package (PoP) คือประกบชิป LPDDR RAM ทับบนหลังชิป SoC โดยตรงเพื่อลดระยะทางลายวงจร เพิ่มความเร็วบัส และใช้ชิปหน่วยความจำแฟลช UFS 3.1 / 4.0 หรือ NVMe สำหรับเก็บ OS และข้อมูล

🧭

Sensors Array (ชุดเซนเซอร์)

ชิปเซนเซอร์ขนาดจิ๋วแบบ MEMS:
• Accelerometer & Gyroscope (ตรวจจับการเอียง/หมุน)
• Proximity Sensor (ดับหน้าจอขณะแนบหู)
• Ambient Light Sensor (ปรับความสว่างจออัตโนมัติ)
• Magnetometer / Barometer (เข็มทิศดิจิทัลและวัดความกดอากาศ)

💳

SIM / eSIM / Secure Enclave

ชิปความปลอดภัยพิเศษสำหรับยืนยันตัวตนในโครงข่ายเซลลูลาร์ (eSIM/iSIM) และจัดเก็บกุญแจเข้ารหัสลับ ลายนิ้วมือ ใบหน้า Face ID เพื่อป้องกันการดักแฮกข้อมูลในระดับฮาร์ดแวร์

สถาปัตยกรรมระบบปฏิบัติการโทรศัพท์เคลื่อนที่ (Mobile Operating Systems)

เปรียบเทียบโครงสร้างชั้นสถาปัตยกรรมซอฟต์แวร์ของ Android (Linux-based) และ iOS (Darwin/XNU-based)

🤖

Android Architecture Stack

1. Applications (System & User Apps)

Phone, Messages, Browser, Third-party Apps (Kotlin/Java)

2. Java API Framework

Activity Manager, Telephony Manager, Location Manager, Window Manager

3. Android Runtime (ART) & Native C/C++ Libraries

AOT/JIT Compilation, SQLite, OpenGL ES, WebKit, Media Framework

4. Hardware Abstraction Layer (HAL)

บริดจ์เชื่อมต่อระหว่างเฟรมเวิร์กกับไดรเวอร์ฮาร์ดแวร์ (Camera, Audio, RIL สำหรับโมเด็ม)

5. Linux Kernel

จัดการหน่วยความจำ (Memory), โพรเซส (Process), ความปลอดภัย, ไดรเวอร์อุปกรณ์ (Hardware Drivers)

🍎

iOS Architecture Stack

1. Cocoa Touch (Application Layer)

UIKit, SwiftUI, MapKit, Push Notifications, Multitasking

2. Media Layer

Core Graphics, Metal, Core Audio, AVFoundation

3. Core Services

Core Foundation, Core Data, Core Location, CloudKit, Security

4. Core OS / Darwin Kernel (XNU)

Mach Microkernel, BSD Unix Subsystem, I/O Kit Drivers, Power Management

💡 ข้อเท็จจริงสำคัญ: ชิปโมเด็มมี OS ของตัวเอง (Real-Time OS)!

ในเครื่องโทรศัพท์เคลื่อนที่ ชิป Baseband Modem จะทำงานแยกจาก Main OS (Android/iOS) อย่างเด็ดขาด และรันระบบปฏิบัติการแบบเรียลไทม์ (RTOS เช่น Nucleus, ThreadX หรือ Linux-based RTOS) เพื่อให้สามารถตอบสนองและประมวลผลคำสั่งจากเสาสถานีฐานได้ภายในเสี้ยวไมโครวินาที โดยติดต่อกับ Android/iOS ผ่าน Radio Interface Layer (RIL)

แบบทดสอบท้ายหน่วยการเรียนรู้ที่ 4

ทดสอบความเข้าใจเกี่ยวกับบล็อกไดอะแกรมฮาร์ดแวร์ ชิปเซ็ต SoC ระบบจัดการพลังงาน และ Mobile OS (5 ข้อ)
