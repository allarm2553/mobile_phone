วิชาโทรศัพท์เคลื่อนที่ (Mobile Phone Technology)

หน่วยที่ 5: การติดตั้ง การตรวจวัด และทดสอบระบบสัญญาณ

RF Measurement Lab

เครื่องวิเคราะห์สเปกตรัมความถี่วิทยุ (Spectrum Analyzer Virtual Lab)

เครื่องมือสำคัญที่สุดในงานโทรคมนาคม ใช้สำหรับตรวจจับสัญญาณคลื่นพาหะ, วัดกำลังส่ง (RF Power), แบนด์วิดท์ (Bandwidth), และสัญญาณรบกวน (Harmonics/Spurious)

Virtual RF Spectrum Screen

หน้าจอจำลองเครื่อง Spectrum Analyzer

เลือกสัญญาณทดสอบ:
Center: 2.600 GHz
Span: 100 MHz
RBW: 100 kHz
Ref Level: -10.0 dBm
Center Frequency & Span

Center Frequency: ความถี่กึ่งกลางช่องสัญญาณที่ต้องการวัด (เช่น 2600 MHz ของ 5G Band n41)
Span: ช่วงความถี่ความกว้างที่ต้องการสแกนดูสัญญาณรอบข้าง

RBW & VBW

Resolution Bandwidth (RBW): ความกว้างตัวกรองความถี่ ยิ่งแคบยิ่งแยกแยะความถี่ใกล้เคียงได้ละเอียด แต่กวาดสัญญาณช้าลง
Video Bandwidth (VBW): กรองสัญญาณรบกวนให้รูปคลื่นเนียนตา

Noise Floor (ระดับสัญญาณรบกวนพื้นฐาน)

เส้นขีดล่างสุดของหน้าจอคือระดับคลื่นรบกวนของเครื่องมือ สัญญาณที่ตรวจวัดได้จริงต้องมีความแรงสูงกว่า Noise Floor ไม่น้อยกว่า 10–20 dB จึงจะสื่อสารได้สมบูรณ์

พารามิเตอร์วัดคุณภาพสัญญาณโทรศัพท์เคลื่อนที่ (Cellular RF Parameters)

3 ตัวชี้วัดสำคัญตามมาตรฐาน 3GPP สำหรับ 4G LTE และ 5G NR ที่วิศวกรและช่างโทรคมนาคมใช้ประเมินสัญญาณ

Signal Strength dBm

RSRP

Reference Signal Received Power

วัด "ความแรงของสัญญาณ" อ้างอิงจากคลื่นพาหะย่อยของสถานีฐาน:

> -80 dBm ดีเยี่ยม (Excellent)
-80 ถึง -90 dBm ดี (Good)
-90 ถึง -105 dBm ปานกลาง (Fair)
< -105 dBm สัญญาณอ่อนมาก (Poor)
Signal Quality dB

RSRQ

Reference Signal Received Quality

วัด "คุณภาพและความสะอาดของสัญญาณ" โดยนำ RSRP เทียบกับ RSSI (กำลังสัญญาณรวมทั้งช่อง):

> -10 dB ดีเยี่ยม (Excellent)
-10 ถึง -15 dB ดี (Good)
-15 ถึง -20 dB ปานกลาง (Fair)
< -20 dB ถูกรบกวนสูงมาก (Poor)
Noise Ratio dB

SINR

Signal-to-Interference-plus-Noise Ratio

อัตราส่วนกำลังสัญญาณต่อกำลังสัญญาณรบกวน เป็นตัวชี้วัดความเร็วเน็ตจริง:

> 20 dB เน็ตเร็วสูงสุด (256-QAM)
13 ถึง 20 dB ความเร็วดี (64-QAM)
0 ถึง 13 dB พอใช้ได้ (16-QAM)
< 0 dB สัญญาณรบกวนมากกว่า (QPSK)

การทดสอบสัญญาณภาคสนาม (Drive Test Simulator)

การขับรถตรวจวัดคุณภาพสัญญาณจริงบนถนนด้วยซอฟต์แวร์ทดสอบ (เช่น TEMS, NEMO) เพื่อหาจุดอับสัญญาณ (Coverage Hole) และจุดที่สายหลุด (Drop Call)

แบบจำลองเส้นทางขับรถทดสอบสัญญาณ (Drive Route)

เลื่อนแถบจำลองระยะทางเพื่อดูการเปลี่ยนแปลงของค่าสัญญาณขณะรถวิ่งออกจากเสาส่ง

ตำแหน่งรถ:
สถานีที่เชื่อมต่อ: Cell Site 1
RSRP (ความแรง): -76 dBm (ดีเยี่ยม)
SINR (คุณภาพ): +24 dB
ความเร็วทดสอบ (Throughput): 380 Mbps
