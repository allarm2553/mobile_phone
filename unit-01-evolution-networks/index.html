Interactive Learning App

เส้นทางวิวัฒนาการระบบสื่อสารเคลื่อนที่

คลิกเลือกยุคการสื่อสารด้านล่างเพื่อสำรวจจุดเด่น เทคโนโลยีหลัก และความเร็วในการรับส่งข้อมูล

สถาปัตยกรรมโครงข่ายเซลลูลาร์ (Cellular Network Architecture)

ทำความเข้าใจการเชื่อมต่อของ 3 ส่วนประกอบหลัก: อุปกรณ์ผู้ใช้ (UE), โครงข่ายภาควิทยุ (RAN) และโครงข่ายหลัก (Core Network)

Network Topology Map

แผนผังจำลองการเชื่อมโยงโครงข่ายทั้งระบบ (End-to-End Network Flow)

สัญญาณวิทยุ (RF) ➔ สถานีฐาน (RAN) ➔ สายไฟเบอร์ (Backhaul) ➔ Core Network
User Equipment

UE (โทรศัพท์ / โมดูล)

เครื่องโทรศัพท์เคลื่อนที่หรืออุปกรณ์ IoT ที่มี SIM Card และชิปเซ็ตภาครับ-ส่งคลื่นความถี่วิทยุ (RF Transceiver) แปลงเสียง/ข้อมูลเป็นคลื่นวิทยุ

คลิกดูการทำงานละเอียด →
Radio Access Network

RAN (สถานีฐานวิทยุ)

โครงข่ายการเข้าถึงทางวิทยุ เช่น BTS (2G), NodeB (3G), eNodeB (4G) และ gNodeB (5G) ทำหน้าที่จัดสรรความถี่ กระจายสัญญาณ และจัดการ Handover

Core Network

Core Network (ระบบแกนกลาง)

ศูนย์รวมการควบคุม การยืนยันตัวตน (Authentication), คิดค่าบริการ, จัดการความต่อเนื่องของสัญญาณ (Mobility) และส่งข้อมูลออกสู่ Internet

เลือกคลิกที่การ์ดด้านบนเพื่อดูข้อมูลส่วนประกอบโครงข่าย

ระบบโทรศัพท์เคลื่อนที่เชื่อมต่อกันด้วยสัญญาณวิทยุระหว่าง UE กับ RAN และเชื่อมต่อจาก RAN เข้าสู่ Core Network ผ่านโครงข่ายสายใยแก้วนำแสง (Fiber Optic Backhaul)

ประเภทของโครงข่ายตามลักษณะการใช้งาน

1. Public Mobile Network (โครงข่ายสาธารณะ)

ให้บริการแก่ประชาชนทั่วไป ดำเนินการโดยผู้ให้บริการเครือข่ายโทรศัพท์เคลื่อนที่ (เช่น AIS, TRUE/DTAC, NT) มีความครอบคลุมทั่วประเทศ

2. Private 5G / Dedicated Network (โครงข่ายเฉพาะกิจ)

โครงข่ายที่สร้างขึ้นเพื่อใช้งานภายในโรงงานอุตสาหกรรม ท่าเรือ หรือคลังสินค้า เพื่อความปลอดภัยสูง ความหน่วงต่ำพิเศษ และการควบคุมข้อมูลเป็นส่วนตัว

ตารางเปรียบเทียบมาตรฐานโครงข่ายแต่ละยุค (Comparison Matrix)

สรุปเปรียบเทียบเชิงวิศวกรรม ตั้งแต่เทคโนโลยีสัญญาณ แบนด์วิดท์ จนถึงบริการเด่น

ยุค (Gen) เทคโนโลยีหลัก วิธีการมอดูเลชัน / ส่งสัญญาณ ความเร็วสูงสุด ความหน่วง (Latency) บริการเด่น
1G AMPS, NMT, TACS Analog FM (FDMA) ~2.4 kbps สูงมาก (ไม่ระบุ) สนทนาเสียงอย่างเดียว
2G / 2.5G GSM, CDMA (IS-95), GPRS, EDGE Digital GMSK / 8-PSK (TDMA/FDMA) 64 kbps - 384 kbps ~300 - 500 ms เสียงชัดขึ้น, SMS, ข้อความ MMS
3G WCDMA, UMTS, HSPA+ CDMA (Spread Spectrum), QPSK, 16QAM 384 kbps - 42 Mbps ~100 - 150 ms Mobile Web, Video Call, โหลดเพลง
4G LTE, LTE-Advanced OFDMA (Downlink), SC-FDMA (Uplink), 64QAM 100 Mbps - 1 Gbps ~30 - 50 ms Streaming HD/4K, เกมออนไลน์, All-IP Voice (VoLTE)
5G 5G NR (New Radio), Standalone (SA) Scalable OFDMA, 256QAM, Massive MIMO, Beamforming 10 Gbps - 20 Gbps < 1 - 5 ms eMBB (ความเร็วสูง), URLLC (ควบคุมระยะไกล), mMTC (IoT นับล้านตัว)
